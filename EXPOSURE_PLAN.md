## What makes the project worth sharing?

- A surprising but **correctly scoped** engineering result.
- A one-command reproduction, before/after trace, and honest limitations.
- Concrete comparisons rather than diagrams alone.
- Clear provenance: official docs vs third-party analysis vs our tests.
- English README, Chinese companion, accessible research abstracts.

## Channel strategies

- **GitHub**: search-friendly title, About/Topics, Releases, pinned repo, reproducible README demo, labeled issues.
- **Technical articles**: publish an original result with data; end with source/reproduction links rather than a Star request.
- **Overseas developer communities**: X, LinkedIn, Hacker News and relevant Reddit communities; comply with posting rules and share only when genuinely useful.
- **Upstream open source**: report reproductions, tests or corrections related to the upstream issue; never post generic advertising or drive-by links.
- **Personal site**: an index page linking each study, source ledger and executable result.

## Content pipeline

Each experiment can become: (1) benchmark result/repository release; (2) 500–900 word English technical note; (3) concise Chinese explanation; (4) one diagram or trace; (5) substantive discussion question. Include no unlicensed Claude Code source excerpts.

## Weekly review

Track:
- Unique visitors, clones/referrers (where available), Stars and watchers;
- external reproductions, meaningful issues/discussions, PRs/citations;
- test success on a clean environment, data completeness;
- conversion rates only when denominators and measurement periods are explicit.

No artificial Star exchanges, fake accounts, bulk unsolicited comments, paid Star schemes, or claims that Stars measure scientific validity.

## Decision gates

- **Publish gate:** runnable evidence + source provenance + limitations.
- **Feedback gate (day 14):** if nobody can reproduce, improve README/setup before seeking more traffic.
- **Product gate (day 30):** expand only features that solve an observed developer pain point.
- **Research gate:** if an experiment cannot distinguish alternative explanations, redesign it before sharing a causal conclusion.

Target **three independent reproductions and five substantive external feedback items** as aspirational milestones; no guaranteed Star count.
