# Contributing

Contribute an independently reproducible experiment, a source correction, or a minimal failure case. Open an issue describing the research question and expected test first.

Pull requests should state:
1. Original evidence and precise scope of claim
2. Independent implementation or changed test
3. Baseline, expected outcome, reproduction command
4. Threats to validity and any negative results

Do not add leaked or proprietary source code. Avoid using real credentials, private logs, or unlicensed datasets.
